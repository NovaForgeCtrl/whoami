## LUMS

### Linux Update Management Server

LUMS is my main open-source project.

The idea is to build a practical Linux update management and reporting platform instead of just writing another small demonstration project.

It combines things I'm currently learning:

* Linux
* Python
* Flask
* SQLite
* Docker
* Nginx
* APT
* Security
* Authentication
* Logging
* System administration

LUMS is still a work in progress.

That's part of the point.

I'm building it while learning — testing ideas, finding problems, fixing them and documenting the process.

**Repository:** [NovaForgeCtrl/LUMS](https://github.com/NovaForgeCtrl/LUMS)

YGGDRASIL is my personal infrastructure and homelab documentation project.

It's where I document experiments and systems around:

* Proxmox
* Linux
* Windows Server
* Networking
* Security
* Monitoring
